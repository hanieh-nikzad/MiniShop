# 🛍️ MiniShop

فروشگاه آنلاین ساده پیاده‌سازی‌شده با Django، شامل مدیریت محصولات، سبد خرید و ثبت سفارش.

## ✨ امکانات

- نمایش محصولات به‌صورت گرید و دسته‌بندی‌شده
- صفحه‌ی جزئیات هر محصول
- سبد خرید با قابلیت افزودن، حذف و تغییر تعداد آیتم‌ها
- ثبت سفارش نهایی و صفحه‌ی تأیید سفارش
- طراحی رابط کاربری ریسپانسیو و راست‌چین (RTL)

## 🛠️ تکنولوژی‌ها

- Python
- Django
- SQLite
- HTML / CSS

## 🚀 نحوه‌ی اجرا

`bash
git clone https://github.com/hanieh-nikzad/MiniShop.git
cd MiniShop
pip install -r requirements.txt
